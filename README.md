## Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/dag0S/portfolio-gosudarev-danila-2.0.git
cd portfolio-gosudarev-danila-2.0

# Устанавить зависимости
npm install

# Запуск в DEV моде
npm run dev

# Сборка проекта
npm run build

# Запуск в PRODUCTION моде
npm run start
```
